How to test

1. Find #define SSID "Your_New_Network_Name" and #define PASSPHRASE "Your_New_Password", update for your wifi and make sure to leave the quotations.
2. Upload code to board
3. Open the serial monitor, ensure baud rate is 115200
4. Hit rst button on board
5. After the board connects to the wifi it will say wifi connected and an IP address in the serial monitor
6. Enter that IP address into the app to connect
